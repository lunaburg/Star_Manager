# 总览页布局

## 当前职责

总览页把当前已建立的本地索引、建议操作、最近任务和本地成就放在一个两列工作区中。HS2 目录是否有效由顶部全局栏显示；总览不再单独维护一个重复的目录状态卡。

## 布局

```text
+---------------------------------------+--------------------------------+
| 总览                                  | 建议操作                       |
| 人物卡 / 模组 / 物品摘要卡             | - 导入外部模组                 |
| 本地成就陈列柜                         | - 一键整理                     |
|                                       | - 重建数据库                   |
|                                       | - 打开角色管理 / 模组管理      |
|                                       | 最近任务                       |
+---------------------------------------+--------------------------------+
```

## 资源摘要

`overviewSummaryCards` 只在目录有效且对应索引已经检查成功时生成卡片：

- 人物卡：`stats.cards`，跳转到角色管理；
- 模组：`stats.zipmods`，跳转到模组管理的模组浏览；
- 物品：`stats.modItems`，跳转到模组管理的物品浏览。

数据库未建立、统计尚未加载或目录无效时，主区域显示“暂无可用统计”，提示选择有效目录并创建数据库。

## 建议操作

当前实现按顺序提供：

1. **导入外部模组**：选择外部目录，提交 `import_external_zipmods`；后端还会处理松散 Unity3D、AIS 角色卡和服装卡。
2. **一键整理**：确认后提交 `organize_all_zipmods_by_author`，把 `mods/` 下的 zipmod 移入作者目录并刷新数据库。
3. **重建数据库**：提交 `build_mod_database`，以增量模式更新模组和角色卡索引。
4. **打开角色管理**：进入 `UserData/chara` 浏览器。
5. **打开模组管理**：进入 zipmod/物品表格。

目录无效或后端未就绪时，相关操作应保持禁用或由主壳层返回明确错误。

## 最近任务

最近任务显示前端已经记录的所有任务，包括导入、整理、数据库、角色卡批量操作和模组批量操作。每行显示任务标题、由 `taskSummary()` 生成的简短结果和 `Done`/百分比/`Error` 状态。任务详情和完整进度消息仍在运行日志及任务轮询状态中，不通过单独的总览接口加载。

## 本地成就

成就陈列柜位于左侧摘要下方，不增加一级导航。当前后端定义五项里程碑：

- 收藏家：收录 1,000 张人物卡；
- 零缺失：完成一次依赖完整的角色卡资源库扫描；
- 考古学家：发现同一 GUID 的三个文件版本；
- 整理大师：清理 10 GB 重复资源；
- 急救医生：修复 100 个缩略图或资源异常。

数据只存储在本地 SQLite。用户可以在总览或设置页调整显示/记录偏好；关闭“隐藏未解锁成就”可查看所有项目；点击项目会打开右侧详情抽屉。关闭成就记录后，不再记录新的修复或清理事件。

## 空状态和错误状态

- 未选择有效目录：显示选择目录和创建数据库的引导，不显示伪造的统计数字。
- 数据库为空：保留建议操作，提示重建数据库。
- 后端不可用：保留静态页面结构，禁用需要后端的动作并显示日志错误。
- 最近任务为空：不渲染“最近任务”面板，避免空容器占据空间。
