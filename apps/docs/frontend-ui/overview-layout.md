# 总览页布局

## 当前职责

总览页把当前已建立的本地索引、建议操作、最近任务和本地成就放在一个两列工作区中。HS2 目录是否有效由顶部全局栏显示；总览不再单独维护一个重复的目录状态卡。四个一级内容容器不显示外部黑色边框，内部摘要卡、成就卡、操作项和任务项仍保留各自的细边框。

### 总览四个容器移除外部边框记录（2026-09-12）

- 背景：总览页四个一级内容容器的黑色粗边框过重，与页面工作区边界形成重复分隔。
- 根因：资源总览、成就陈列柜、建议操作和最近任务都继承了通用 `.panel` 的 `3px` 外部边框。
- 解决方案：为总览页四个直接面板增加专属覆盖规则，设置 `border: 0`；内部卡片和列表项的边框保持不变。
- 验证结果：通过 `npm run build` 和 `git diff --check` 验证；四个一级容器外部边框消失，内部内容布局和交互保持不变。
- 适用边界：仅影响总览页四个一级 `.panel` 容器，不改变其他页面面板或总览页内部卡片的边框样式。

### 总览成就陈列柜移除英文副标题记录（2026-09-12）

- 背景：成就陈列柜标题上方的 `LOCAL ARCHIVE` 与中文标题信息重复，增加了不必要的视觉层级。
- 根因：成就头部模板额外渲染 `.achievement-kicker` 文案及其专用样式。
- 解决方案：移除 `LOCAL ARCHIVE` 文案和对应样式，让“成就陈列柜”直接作为头部标题显示。
- 验证结果：通过 `npm run build` 和 `git diff --check` 验证；英文副标题消失，成就计数、卡片和详情交互保持不变。
- 适用边界：仅影响总览页成就陈列柜的标题文案，不改变成就数据、进度或偏好设置。

### 总览建议操作与最近任务改为透明玻璃样式记录（2026-09-12）

- 背景：总览右侧“建议操作”和“最近任务”中的列表项仍使用较实的粉色或浅色背景，与页面已有的半透明磨砂面板不一致。
- 根因：`.action-item` 与 `.task-item` 继承了不透明的 `var(--surface-soft)` 背景，缺少背景透叠和统一的边缘高光。
- 解决方案：仅在 `.overview-grid` 范围内为两类列表项增加半透明玻璃背景、背景模糊、浅色细边缘和轻微内沿/外发光；保留“一键整理”的低透明度黄色警示色，并补充悬停与键盘聚焦反馈。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；建议操作和最近任务的文字、任务状态徽标、布局及点击行为保持不变。
- 适用边界：仅影响总览页右侧两类列表项，不改变其他页面的 `.action-item`、`.task-item` 或总览业务逻辑。

### 总览最近任务改为滚动列表记录（2026-09-12）

- 背景：最近任务原先最多保留 5 条，较早完成的任务会从总览页中消失，无法继续查看。
- 根因：前端 `rememberTask()` 使用 `.slice(0, 5)` 截取任务数组。
- 解决方案：移除前端的 5 条截取限制，为最近任务面板增加固定工作区内的纵向滚动容器和可见滚动条；任务仍按最近更新顺序排列。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；任务列表超出面板高度时可通过滚动条查看较早任务，同一任务更新不会重复显示。
- 适用边界：任务记录仍仅存在当前前端会话内，不改变后端任务存储、任务执行或运行日志行为。

### 总览最近任务单项保持原高度记录（2026-09-12）

- 背景：滚动容器启用后，Grid 默认会拉伸内容不足时的任务行，单个任务项占满最近任务面板的剩余高度。
- 根因：任务列表的自动行轨道和默认内容对齐方式允许任务项垂直拉伸。
- 解决方案：为总览任务列表设置 `grid-auto-rows: max-content` 和 `align-content: start`，让每个任务项保持原有内容高度，剩余空间仍由列表滚动区域承载。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；单个任务项不再填满容器，多条任务超出高度时仍可滚动查看。
- 适用边界：仅调整总览页最近任务列表的行高与滚动布局，不改变任务排序、数量或任务状态展示。

### 总览页移除标题和面板边缘细线记录（2026-09-12）

- 背景：总览页面标题下方以及成就陈列柜右侧、底部出现细分隔线，与透明玻璃面板的无边界视觉目标不一致。
- 根因：通用 `.module-head` 的底部边框、总览面板的玻璃内阴影，以及成就陈列柜伪元素的装饰性边框共同形成了这些细线。
- 解决方案：仅在总览页移除直接面板的标题底边和内阴影，并取消成就陈列柜伪元素的边框及内阴影；保留成就卡片、操作项和任务项自身的边界与交互反馈。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；总览标题栏和面板边缘细线消失，内容布局与业务交互保持不变。
- 适用边界：仅影响总览页四个直接面板及其成就陈列柜装饰层，不改变其他页面的标题栏、面板或卡片边框。

### 总览成就卡片下移记录（2026-09-12）

- 背景：总览页成就陈列柜中的卡片与标题区域间距偏紧，需要增加少量呼吸空间。
- 根因：嵌入式成就网格的顶部内边距为零，卡片直接从标题区域下方开始排列。
- 解决方案：仅为总览页嵌入式成就网格增加 10px 顶部内边距，使红框内的成就卡片整体下移，同时保持卡片尺寸、列数和交互不变。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；成就标题、计数和卡片点击详情功能保持正常。
- 适用边界：仅影响总览页成就陈列柜，不改变其他页面或成就抽屉中的布局。

### 总览页移除成就计数记录（2026-09-12）

- 背景：成就陈列柜标题右侧的“已解锁 / 总数”计数位于较空的区域，形成多余视觉信息。
- 根因：成就头部模板额外渲染 `.achievement-count` 计数控件及其黄色强调样式。
- 解决方案：移除总览成就陈列柜中的计数控件和对应样式；成就数据、解锁状态与详情抽屉逻辑保持不变。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；标题和成就卡片正常显示。
- 适用边界：仅影响总览页成就陈列柜标题区域，不改变后端成就统计或其他页面的计数显示。

## 资源摘要

`overviewSummaryCards` 只在目录有效且对应索引已经检查成功时生成卡片：

- 人物卡：`stats.cards`，跳转到角色管理；
- 模组：`stats.zipmods`，跳转到模组管理的模组浏览；
- 物品：`stats.modItems`，跳转到模组管理的物品浏览。

数据库未建立、统计尚未加载或目录无效时，主区域显示“暂无可用统计”，提示选择有效目录并创建数据库。

### 总览资源摘要卡移除辅助文字记录（2026-09-12）

- 背景：界面参考要求删除资源摘要卡底部的“AIS PNG”“本地索引”和“模组 + 本体”辅助文字，减少卡片内的重复信息。
- 解决方案：移除摘要卡的辅助文字渲染及对应数据字段，仅保留“人物卡 / 模组 / 物品”标题和数量；卡片点击跳转保持不变。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；摘要统计和跳转逻辑正常。
- 适用边界：仅影响总览页资源摘要卡的展示文字，不改变统计来源、数据库状态判断或目标页面。

## 建议操作

当前实现按顺序提供：

1. **导入外部模组**：选择外部目录，提交 `import_external_zipmods`；后端会识别标准结构的 `.zip` 并将导入副本规范为 `.zipmod`，同时处理松散 Unity3D、AIS 角色卡和服装卡。无效 `.zip` 会在结果面板列为跳过项，外部原文件保留不动。
2. **一键整理**：确认后提交 `organize_all_zipmods_by_author`，把 `mods/` 下的 zipmod 移入作者目录并刷新数据库。
3. **重建数据库**：提交 `build_mod_database`，以增量模式更新模组和角色卡索引。
目录无效或后端未就绪时，相关操作应保持禁用或由主壳层返回明确错误。

### 总览建议操作移除角色管理与模组管理入口记录（2026-09-12）

- 背景：界面参考要求删除“建议操作”区域中“打开角色管理”和“打开模组管理”两个入口按钮，避免与全局导航及资源摘要卡的跳转功能重复。
- 解决方案：移除总览页对应的两个操作项，保留导入外部模组、一键整理和重建数据库三个建议操作。
- 验证结果：通过 `npm run build` 与 `git diff --check` 验证；其它建议操作、资源摘要卡和全局导航不受影响。
- 适用边界：仅影响总览页“建议操作”列表，不删除角色管理或模组管理页面，也不改变其导航入口和业务逻辑。

## 最近任务

最近任务显示前端已经记录的任务，包括导入、整理、数据库、角色卡批量操作和模组批量操作。任务数量不再限制为 5 条；超出面板可用高度时，通过面板内纵向滚动条查看较早任务。每行显示任务标题、由 `taskSummary()` 生成的简短结果和 `Done`/百分比/`Error` 状态。任务行是可点击按钮，点击后打开任务详情抽屉，展示状态、完成指标、开始/结束时间、完整任务消息；`build_mod_database` 额外展示原版资源索引、zipmod 扫描、物品解析、数据库写入、人物卡数据库和总耗时。任务快照仅保留在当前前端会话内，不通过单独的总览接口加载。

### 最近任务详情与数据库耗时汇总记录（2026-09-14）

- **背景**：数据库重建日志只有阶段进度消息，没有阶段耗时汇总；总览页最近任务只能查看摘要，无法回看任务完成情况。
- **根因**：后端任务状态没有 `finished_at` 或结构化计时字段，前端 `rememberTask()` 只保存标题、摘要和状态徽标，最近任务条目也不是可交互控件。
- **解决方案**：`build_mod_database` 记录并返回六项毫秒耗时：原版资源索引、zipmod 扫描、物品解析与缩略图、模组数据库写入、人物卡数据库和总耗时；完成时向任务消息追加秒数汇总。任务状态新增 `finished_at`。总览页保存任务快照，将最近任务行改为可点击按钮，并通过玻璃化右侧抽屉展示耗时、数据库统计、任务消息和时间信息。
- **验证结果**：通过 Python 语法检查、`npm run build` 和 `git diff --check` 验证；任务接口契约同步记录于 `apps/docs/backend-interface.md`。
- **适用边界**：任务历史仍是当前前端会话内存数据；应用重启后不会恢复旧任务。缩略图 profiling 文件仍保留单个物品级诊断记录，与任务详情中的阶段耗时汇总互补。

## 本地成就

成就陈列柜位于左侧摘要下方，不增加一级导航。当前后端定义五项里程碑：

- 收藏家：收录 1,000 张人物卡；
- 完美主义者：完成一次依赖完整的角色卡资源库扫描；
- 考古学家：发现同一 GUID 的三个文件版本；
- 整理大师：清理 10 GB 重复资源；
- 急救医生：修复 100 个缩略图或资源异常。

五项成就分别使用对应的 64×64 像素徽章图标：收藏家使用收藏宝箱，完美主义者使用金色桂冠与完成标记，考古学家使用带放大镜的档案盒，整理大师使用分类收纳柜，急救医生使用医疗十字与药瓶。图标资源位于 `apps/src/assets/achievement-*.png`，通过 `apps/src/achievementIcons.js` 按成就 ID 映射；成就 ID 和本地解锁记录保持不变。

点击成就后打开的详情抽屉采用横向头部：徽章位于左侧，成就名称位于徽章右侧，描述与进度信息从头部下方开始。

数据只存储在本地 SQLite。用户可以在总览或设置页调整显示/记录偏好；关闭“隐藏未解锁成就”可查看所有项目；点击项目会打开右侧详情抽屉，详情仅展示状态和首次解锁时间。关闭成就记录后，不再记录新的修复或清理事件。

## 空状态和错误状态

- 未选择有效目录：显示选择目录和创建数据库的引导，不显示伪造的统计数字。
- 数据库为空：保留建议操作，提示重建数据库。
- 后端不可用：保留静态页面结构，禁用需要后端的动作并显示日志错误。
- 最近任务为空：不渲染“最近任务”面板，避免空容器占据空间。
