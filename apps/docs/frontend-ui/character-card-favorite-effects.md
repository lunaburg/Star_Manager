# 人物卡收藏视觉状态

## 当前结论

已收藏人物卡使用可配置的完整视觉主题，作为收藏状态的主要视觉提示；一套主题同时包含网格人物卡框、人物卡名字字体与铭牌、详情页人物卡图像边框和卡面特效。网格卡片不再使用右上角星标。默认主题为“鎏金流彩”，也可在设置页切换为“霓虹炫彩”“樱落绮梦”或“黑曜鎏火”。人物图显示区域、名字字号和对齐方式与普通卡一致。

收藏状态由人物卡边框和不透明铭牌共同表示。人物卡详情中的收藏按钮继续独立工作，网格卡片不再显示右上角星标。

仅收藏卡的名字栏移除原有粉色背景，改为与外框主题一致的不透明铭牌；“鎏金流彩”使用金色铭牌；“霓虹炫彩”使用参考图风格的深黑紫铭牌、双色霓虹边线与缓慢交错光带，名字内部固定为纯白，仅在文字外圈保留洋红/青色错位边缘与低频呼吸光晕；“樱落绮梦”使用酒红漆面铭牌、暖白字与淡金描边。普通卡继续使用原有粉色渐变标题栏，保持现有视觉不变。

## 当前模板结构

人物卡网格位于 `apps/src/components/views/CharactersView.vue`。关键结构为：

```text
.char-card
|-- .portrait
`-- .card-caption
    `-- strong
        `-- .card-name-text
```

收藏卡仍会添加 `favorite` class；选择“霓虹炫彩”时额外添加 `favorite-theme-neon`，选择“樱落绮梦”时额外添加 `favorite-theme-sakura`，选择“黑曜鎏火”时额外添加 `favorite-theme-obsidian`。这些 class 负责启用边框及光晕，不能改变人物图的尺寸或裁切方式。“樱落绮梦”使用 `.card-theme-petals` 承载少量装饰花瓣，“黑曜鎏火”使用 `.card-theme-embers` 承载细小火星，两者都不拦截交互。

模板不再输出 `data-name-effect`、`data-border-effect` 或 `.card-name-starlights`。

## 名字显示

- 收藏卡和普通卡统一使用 `13px` 字号。
- 名字在标题栏中水平、垂直居中。
- 普通卡标题栏继续使用原有粉色渐变；收藏卡铭牌使用与外框一致的金色渐变、高光和边线，不使用透明背景。
- 名字溢出时继续通过 `v-card-name-scroll` 指令滚动显示。
- `prefers-reduced-motion: reduce` 下停止滚动并使用省略显示。

## 设置与持久化

“开始游戏”页不提供“收藏卡片样式”设置；设置页的“人物卡外观”区域提供边框主题选择。

Electron 设置使用 `favoriteCardTheme` 保存主题，合法值为：

- `gold`：鎏金流彩（默认）
- `neon`：霓虹炫彩
- `sakura`：樱落绮梦
- `obsidian`：黑曜鎏火

前端状态、Electron 设置规范化以及卡片模板均不再读取或保存：

- `cardNameEffect`
- `cardBorderEffect`

旧版 `settings.json` 中即使残留这两个字段，也不会影响当前界面；后续保存设置时会由规范化流程自然丢弃。缺失或非法的 `favoriteCardTheme` 会回退为 `gold`；短期实现中出现过的 `favoriteCardFrameTheme` 会迁移到新字段。

## 修改规则

1. 收藏状态通过当前边框特效主题和配套铭牌表示，不在网格卡片上显示右上角星标。
2. 默认的 `.char-card.favorite` 使用单圈加厚相框：内圈保留金色流光，外圈使用玫瑰铜、香槟金、蜜桃金和浅粉金组成的暖色玫瑰金流彩渐变并循环流动，同时配合暖色移动外发光，不使用紫色；底部铭牌使用不透明深浅金渐变并显示横向流光，人物名字使用洋红、纯黄、荧光青和深蓝组成的高对比渐变流彩字。
3. `.favorite-theme-neon` 使用紫、蓝、青、洋红和珊瑚粉构成的细霓虹渐变边框与克制外发光；底部使用深黑紫不透明铭牌、双色霓虹边线和交错光带，人物名字的笔画内部保持纯白，仅在外圈叠加洋红/青色错位边缘与低频呼吸光晕；详情卡面使用专属的冷暖双色边缘反射与对角扫光，以匹配参考图。不得对人物图增加滤镜或暗色遮罩。
4. `.favorite-theme-sakura` 使用象牙白与樱粉漆面框，并以玫瑰金色段落局部包边；底部使用酒红渐变铭牌，人物名字使用暖白字与淡金描边；网格卡面和详情卡面使用浅樱粉、暖象牙色柔雾与低频扫光，仅从上方一侧错峰飘落五枚以内的半透明花瓣。
5. `.favorite-theme-obsidian` 使用炭黑与深褐黑曜石框，裂隙透出暗红、熔橙与少量亮金并周期性明暗变化；底部使用炭黑铭牌，人物名字使用象牙白字与余烬红外光；网格和详情卡面只在边缘保留烟黑与暗红热反射，从底部错峰升起六枚以内的细小火星，不得给人物图叠加大面积暗色遮罩。
6. 详情预览中的卡面保持原图清晰度，仅通过半透明玻璃高光、反射扫光和主题化边缘厚度感表现材质，不使用背景模糊或人物图滤镜，但不得遮挡人物图或缺失依赖徽标。
7. 普通卡的 `.card-caption` 保持原有样式；仅 `.char-card.favorite .card-caption` 使用主题对应的不透明铭牌，并与外框保持同一套视觉层次。
8. 边框、光雾、裂纹和装饰粒子动画应保持低频、克制，并在 `prefers-reduced-motion: reduce` 下停用；减少动态效果时隐藏花瓣与火星。
9. 收藏边框和装饰效果不能遮挡选中勾选、缺失依赖徽标或详情操作按钮。
10. 长名字滚动不能阻挡卡片点击或键盘操作。

## 关键文件

- `apps/src/components/views/CharactersView.vue`：收藏 class、名字结构与溢出检测。
- `apps/src/components/views/SettingsView.vue`：完整人物卡主题选择与主题范围说明。
- `apps/src/styles.css`：普通卡片视觉、收藏边框与流光、详情预览边框和长名字滚动。
- `apps/src/App.vue`：收藏状态操作与全局上下文。
- `apps/electron/main.cjs`：应用设置规范化与持久化。

完成人物卡前端修改后，从 `apps/` 运行：

```powershell
npm run build
```
