# UI 风格规范

## 方向

Star_Manager 应像一个轻量、友好的桌面资源管理器。当前预览方向是“柔和桌面工具 + 粗描边控件”：粉蓝强调、白色内容面板、黑色描边、实体投影和清晰的资源管理层级。

界面可以可爱，但必须让用户相信它适合管理真实文件。

## 视觉原则

- 使用稳定的左侧导航列。
- 模块内容保持明亮、留白充足。
- 资源浏览优先使用卡片。
- 只有在需要精确扫读时使用表格。
- 详情和日志默认不要占据主视觉路径。
- 高风险操作绝不能表现得像轻量 toggle。
- 控件可以有一点玩具感，但信息架构必须像可靠的文件管理工具。

## 色彩

推荐角色：

- 应用背景：冷调浅蓝到白色，再过渡到极浅粉色。
- 表面：白色。
- 主强调色：柔和粉色，用于当前导航和选中分类。
- 次强调色：浅蓝色，用于主按钮、当前导航图标和积极操作。
- 安全状态：青绿色或绿色。
- 警告状态：琥珀色。
- 高风险状态：红色。
- 文本：主文本近黑，次要文本使用柔和灰。

避免让整个应用变成单一粉色主题。粉色用于引导注意，而不是覆盖所有界面。

## 字体

中英文界面文本使用系统 UI 字体。

推荐尺寸：

- 页面标题：20-24 px。
- 区块标题：16-18 px。
- 正文：13-15 px。
- 元数据和徽标：12-13 px。
- GUID、路径和日志：等宽字体。

不要根据视口宽度缩放字体。标签应短而稳定。

## 左侧栏

左侧栏样式：

- 宽度：当前预览 250 px，可在 240-280 px 内调整。
- 背景：接近白色的暖调表面。
- 面板：黑色粗描边，圆角约 22 px，实体投影。
- 当前项：柔和粉色到浅蓝渐变背景，黑色描边和短投影。
- 图标加文字，图标为两字母缩写。
- 如果增加二级分组，使用清晰分组标题。

导航项文字不应换行。如果文字太长，应缩短标签。

侧栏只承载品牌和主导航，不固定显示安全上下文区域，也不放“导出诊断信息”入口。

## 顶部全局栏

顶部全局栏样式：

- 高度当前预览为 76 px。
- 与侧栏同样使用白色表面、黑色粗描边、圆角和实体投影。
- 左侧放 HS2 目录选择和当前路径，中间放任务进度，右侧只放单一全局操作“重建数据库”。
- 路径和任务 ID 使用等宽字体或稳定数字字形。
- 任务进度条保持细而清晰，不抢过模块内容。

## 卡片

资源卡片：

- 圆角约 12-18 px；人物卡可使用更明确的 14-18 px。
- 白色表面。
- 黑色描边和实体投影是当前预览的主要质感。
- 状态徽标放在一致位置。
- 资源主名称清晰可见。
- 元数据放在名称下方成组展示。

角色卡片应强调大缩略图，并在底部使用浅粉或浅橙信息条显示名称。Zipmod 卡片应强调名称、作者、GUID 和状态。

人物卡选中态只使用右上角圆形勾选徽章，不额外增加粗边框、底部状态条或“已选”文字。

## 工具栏

工具栏控件：

- 搜索输入框放左侧。
- 筛选器紧随搜索。
- 排序和视图控件放右侧。
- 模块操作放最右侧。

刷新、打开目录、导出、切换视图等低频操作不放在顶部全局栏；如在模块工具栏或详情区使用图标按钮，仅图标按钮需要 tooltip。

人物卡浏览器标题栏右侧不放 `REF`、`LG`、`...` 这类孤立小按钮；刷新属于模块工具栏或状态变化触发，视图密度和排序属于工具栏。

## 详情抽屉

详情抽屉应：

- 固定宽度约 360-440 px。
- 顶部展示选中资源标题。
- 分组展示元数据、依赖、路径和操作。
- 在用户浏览时保持打开，并随选择变化更新内容，避免频繁弹窗打断。

只在确认、阻塞错误或聚焦表单时使用模态弹窗。

## 角色卡目录

角色卡库的右侧区域优先用于“卡片目录”，而不是常驻详情抽屉。

卡片目录样式：

- 固定宽度约 280-340 px。
- 标题为“卡片目录”。
- 使用树形层级展示 `UserData/chara`。
- 节点数量使用柔和粉色徽标。
- 当前选中节点使用浅灰或浅粉底。
- 展开/折叠按钮保持小而清晰。
- 目录树独立滚动，底部可提供隐藏/收起按钮。

## 风险状态

高风险 UI 必须明显区分：

- 红色或琥珀色风险标题。
- 清楚解释将要改变什么。
- 影响文件数量。
- 源路径和目标路径。
- 可用时提供更安全的替代操作。
- 具体确认按钮文案。

示例：

- `确认移动 128 个 zipmod`
- `确认删除 14 个空目录`
- `确认整理游戏目录中的文件`

避免使用 `OK`、`Yes`、`确定` 这类泛化确认文案。

## 空状态

空状态应具体且有用。

示例：

- 未选择游戏目录：显示预期 HS2 文件夹和目录选择器。
- 未建立索引：显示扫描操作。
- 当前文件夹没有角色卡：显示选中文件夹路径。
- 后端不可用：显示重试操作，并禁用后端操作。

## 参考图适配

可借鉴参考图中的：

- 柔和侧边栏。
- 粉色当前导航。
- 图标化分类网格。
- 上方浏览、下方或右侧详情信息的分区工作区。
- 模块标题栏附近的紧凑工具按钮。

不要借鉴：

- 会员、积分、云商城或游戏化经济元素。
- 将高风险文件操作做成随手可点的 toggle。
- 与 Star_Manager 工作流无关的纯装饰控件。

## 像素风格层

当前预览在“桌面资源管理器 + 粗描边控件”的基础上叠加像素风格，而不是转成完整游戏菜单。

- 背景使用 16px 网格或低对比重复纹理，不能影响表格、路径和 GUID 的阅读。
- 主面板、顶部栏、侧栏和资源卡保持粗黑边，但圆角收敛到 4-8px，避免过度柔和。
- 硬边块状投影只用于真正可点击的按钮；其他控件、容器、卡片、徽标和详情块不使用投影。
- 按钮保留明确按压反馈，但移动距离以 2px 为主，避免布局跳动。
- 分段控件、tab 组、筛选组和按钮行的父容器只使用细边、浅底或留白分组，不使用按钮式粗黑边、硬投影和按压状态。
- 表格选中行、tab 组、筛选组和普通信息块不使用条纹背景；像素感主要通过硬边、低圆角、网格背景和少量缩略图纹理表达。
- 头像、缩略图和占位图使用 `image-rendering: pixelated`，但正文、表格和日志文本保持清晰。
- 像素化只作为视觉材质，不改变信息密度、风险分区和安全确认规则。
