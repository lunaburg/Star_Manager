# 总览页布局

## 目标

总览页回答三个问题：

- 当前选择的游戏目录是否有效？
- 资源库里有哪些资源和问题？
- 用户下一步应该做什么？

## 布局

当前预览使用左右两列卡片布局：

```text
+---------------------------------------+--------------------------------+
| 总览                                  | 建议操作                       |
| 资源健康摘要卡 5 张                    | - 重建数据库                   |
|                                       | - 查看依赖问题摘要             |
| 游戏目录状态                          | - 打开角色管理                 |
| - mods OK                             | - 打开模组管理                 |
| - abdata OK                           |                                |
| - UserData/chara OK                   | 最近任务                       |
+---------------------------------------+--------------------------------+
```

推荐区域：

- 总览标题卡，说明“目录校验、资源健康、最近任务和建议操作”。
- 资源健康摘要卡。
- 游戏目录状态卡。
- 建议操作列表。
- 最近任务列表。

## 游戏目录状态

展示：

- 当前 HS2 根目录路径。
- 校验结果。
- 如果目录无效，展示缺失的预期目录。
- 最近一次成功扫描时间。
- 重新选择目录按钮。

预期 HS2 目录：

- `mods`
- `abdata`
- `UserData/chara`

## 资源摘要

摘要卡：

- 角色卡。
- Zipmods。
- 缺失 zipmods。
- 缺失 `abdata/unity3d`。
- 错误 zipmods。

每张摘要卡应链接到对应模块。

当前预览示例：

- `角色卡 / 1,079 / AIS PNG`。
- `Zipmods / 8,214 / 本地索引`。
- `缺失 / 23 / zipmod GUID`。
- `缺失 / 4 / abdata/unity3d`。
- `错误 / 12 / zipmod`。

## 建议操作

示例：

- 扫描索引。
- 查看依赖问题摘要。
- 打开角色卡库。
- 打开 Zipmod 库。
- 查看失败任务。

只显示当前有效的操作。如果未选择游戏目录，主操作应为选择 HS2 游戏目录。

当前预览文案：

- 重建数据库：重新生成角色卡和 zipmod 本地索引。
- 查看依赖问题摘要：定位缺失 zipmod。
- 打开角色管理：浏览 `UserData/chara/female`。
- 打开模组管理：以表格查看 zipmod。

## 最近任务

最近任务是辅助信息，不应抢占资源摘要和建议操作的视觉优先级。

当前预览示例：

- `extract_dependencies`：17 张人物卡，Copy 模式，状态 `42%`。
- `scan_zipmods`：完成，新增 128 条，状态 `Done`。
- `read_setup`：setup.xml utf-16，状态 `Done`。

## 空状态和错误状态

未选择游戏目录：

- 显示清晰空状态。
- 提供主目录选择按钮。
- 简短说明预期 HS2 目录结构。

后端不可用：

- 显示后端错误状态。
- 保留静态摘要区域。
- 禁用扫描和任务操作。
